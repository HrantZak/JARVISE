# Создание файлов голосом

Скажите «Жарвис, создай Word-документ про тигра» или введите просьбу на странице «Файлы» либо «Диалоги». Для голосового ввода должны быть настроены распознавание и микрофон. Для написания содержимого нужен подключённый DeepSeek и включённый агент с разрешением безопасных действий.

Примеры:

- «Создай Word-документ про тигра с разделами про питание и среду обитания».
- «Создай папку Проекты» — эта простая команда работает без API.
- «Создай файл hello.py с кодом, который выводит приветствие».
- «Создай текстовый файл План.txt со списком дел на завтра».

Результаты сохраняются в системной папке «Документы», в подпапке JARVIS. После сохранения Jarvis показывает фактический путь на экране, а вслух говорит только «Готово, сэр». Спросите «Где ты его сохранил?» — он назовёт путь к последнему результату текущего сеанса. На странице «Файлы» кнопка «Открыть папку» открывает расположение последнего результата. Запросы обрабатываются по одному файлу или папке; вложенную папку нужно создать заранее.

Word-документы создаются в формате DOCX с заголовком, разделами, списками и номерами страниц. Для создания Word не требуется. Для просмотра нужен совместимый редактор. Содержимое ограничено 32 000 символами; форматирование таблиц и иллюстрации пока не поддерживаются.

Существующие файлы не перезаписываются. Пути вне папки JARVIS и недопустимые имена отклоняются. Созданный код сохраняется в файл и автоматически не запускается. Если модель не подготовила корректный вызов инструмента или сохранить файл не удалось, Jarvis сообщает об ошибке, а не об успешном создании.
