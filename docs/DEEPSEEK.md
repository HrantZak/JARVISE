# DeepSeek API

Откройте Jarvis → DEEPSEEK API, вставьте свой готовый ключ и нажмите «Сохранить и подключить».
Приложение проверяет доступ к модели через API и сохраняет ключ в Windows Credential Manager. Следующий запуск использует его автоматически. Замена ключа очищает диалог; во время выполнения задания переключение подключения блокируется.

Используется deepseek-v4-flash. По умолчанию выбран «Баланс»: простые запросы идут с thinking disabled, сложные по эвристике — с thinking enabled и reasoning_effort high. Пользователь может выбрать «Быстро» или «Подробно». Качество классификации не гарантируется; режим «Подробно» принудительно включает углублённый разбор. Скрытое рассуждение не выводится в чат. Ответ передаётся потоком.

«Характер Jarvis» добавляет спокойный стиль и уместные короткие реплики с обращением «сэр», избегая постоянного повторения.

Без ключа облачная модель не подключается. Локальные модели больше не выбираются и автоматически не загружаются. Проверка ключа запрашивает сведения о модели, без генерации текста; доступная квота проверяется при настоящем запросе.

`scripts/start-deepseek.ps1` позволяет использовать ключ окружения. `DEEPSEEK_API_KEY` читается, только если сохранённого ключа нет. Для полного отключения ключа из окружения удалите также эту переменную в Windows. Не записывайте ключ в память или сценарий.

Текст диалога, включённая память, результаты инструментов и явно выбранный для анализа текст отправляются DeepSeek. Аудио распознаётся и озвучивается локально. Скорость зависит от сервиса и сети; квоты и оплата определяются аккаунтом DeepSeek.

Запуск: `build/msvc-release/bin/JARVIS.exe`. Сборка: `scripts/build.bat release`.
Официальная документация: https://api-docs.deepseek.com/ и https://api-docs.deepseek.com/api/create-chat-completion/.
