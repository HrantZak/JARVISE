# CMD и PowerShell в Jarvis

Откройте «Диалоги» и напишите команду с префиксом:

- `CMD: ver`
- `CMD: ipconfig /all`
- `PowerShell: Get-Process | Select-Object -First 10 ProcessName, Id`

Перед произвольной командой Jarvis показывает точный текст, оболочку и папку запуска. Нажмите «Разрешить» для выполнения или «Отмена». Подтверждение одноразовое и действительно только для этой команды и задачи. В случае ошибки команда не повторяется автоматически.

Готовые проверки запускаются без подтверждения: «проверь интернет», «проверь сеть», «проверь процессы», «проверь место на диске», «версия Windows». Проверка сети показывает конфигурацию и доступность 1.1.1.1 по ICMP; отрицательный ответ ICMP сам по себе не доказывает отсутствие интернета. Все проверки требуют включённых инструментов и разрешения чтения данных.

DeepSeek также может составить команду по обычной просьбе. Даже в этом случае произвольный текст перед запуском показывается пользователю. Для точной команды с префиксом CMD/PowerShell и готовых проверок API-ключ не нужен. Для голосового ввода сначала скажите «Жарвис»; сложную команду с путями и кавычками удобнее ввести текстом.

Выполнение идёт в фоне, с пониженным приоритетом процесса. Результат, ошибки и код завершения появляются в чате. Лимит — 120 секунд, вывод ограничен 64 КиБ. «Стоп» завершает процесс и его дочерние процессы в группе Windows Job Object. Отмена не отменяет уже внесённые командой изменения.

По умолчанию рабочая папка — `%LOCALAPPDATA%/JARVIS/commands`. Инструмент `run_shell` принимает необязательный `working_directory` — существующий абсолютный путь, который также показывается при подтверждении. Интерактивный ввод, длительные службы и фоновые задачи не поддерживаются. Права автоматически не повышаются; процесс наследует права Jarvis. CMD запускается с отключённым AutoRun, PowerShell — без профиля.

Проверено: настоящие CMD/PowerShell, русский вывод, ненулевые коды завершения, большой вывод, тайм-аут, отмена, завершение дочернего процесса, одноразовое подтверждение и привязка к задаче. 11 проверок нового набора прошли; вместе с ним прошли 8 наборов регрессионных тестов. Окно подтверждения проверено в собранном приложении без исполнения показанной команды.
