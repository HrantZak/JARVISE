# JARVIS для Windows

Настольный ассистент на C++23 и Qt Quick. Ответы формирует DeepSeek API; распознавание выполняется локально через Whisper, озвучивание — нейросетевым голосом Piper.

## Запуск

Запустите `build/msvc-release/bin/JARVIS.exe`. Не переносите EXE отдельно от соседних DLL и папок Qt.
Откройте **DEEPSEEK API**, вставьте собственный ключ и нажмите **Сохранить и подключить**. Ключ хранится в Windows Credential Manager. Интернет и доступная квота DeepSeek необходимы для ответов.

## Возможности

- Создание папок, текстовых файлов, файлов с кодом и оформленных Word-документов по голосовой или текстовой просьбе. Результаты — в «Документы/JARVIS», путь и открытие папки — на странице «Файлы». Примеры и ограничения: `docs/CREATION.md`.
- Управление окнами и браузером: открытие приложений и игр по ярлыкам, новая и текущая вкладка, закрытие окна, разворачивание и перенос на монитор. Команды и подтверждения: `docs/WINDOWS.md`.
- Потоковые ответы DeepSeek, остановка генерации и история текущего диалога.
- Режим «Баланс»: быстрые обычные ответы, reasoning для запросов, которые эвристика определяет как сложные. Режимы «Быстро» и «Подробно» позволяют переопределить выбор.
- Характер Jarvis: спокойный тон, обращение «сэр», короткие реплики по ситуации. Это стилизация, а не полный набор цитат из фильмов.
- Память о разрешённых пользователем фактах с отдельным включением сохранения между запусками.
- Запуск и закрытие приложений через агент и существующие проверки разрешений.
- Просмотр текстовых файлов до 128 КиБ; отправка первых 12 000 символов на анализ только по кнопке.
- Один сохраняемый сценарий с ручным запуском и остановкой. Планировщика по времени нет.
- Системная телеметрия, инструменты, настройки безопасности и голосовой конвейер.

## Голос и нагрузка

Распознавание загружается в фоне по требованию. По умолчанию используется до четырёх потоков процессора; на странице «Голос» можно выбрать 2/4/8 и использование видеокарты. Эти настройки требуют перезапуска. Поддержка GPU зависит от оборудования и сборки. Локальная языковая модель автоматически не загружается.

Для голоса нужны модель Whisper, Piper и его голосовые модели. По умолчанию используются установленные в `%USERPROFILE%/.helolo/voice` русская модель «Дмитрий» и английская «Ryan»; пути можно задать в конфигурации. Windows Pavel больше не используется в приложении. Высота голоса естественная, темп немного замедлен, тембр слегка смягчён эквализацией; применяется словарь чтения названий и сокращений. Текст ответа на экране остаётся прежним. Клонирование удалено; озвучка работает локально, без Python, API и модели на видеокарте. При несовпадении форматов динамиков PCM преобразуется с сохранением длительности и высоты голоса.

## Данные

Настройки и журналы обычно находятся в `%LOCALAPPDATA%/JARVIS`; при недоступности используется `JARVIS-data` рядом с EXE. Постоянная память хранится в `data/memory.txt`. Сценарий использует системное хранилище настроек Qt. Переменная `JARVIS_DATA_ROOT` позволяет выбрать другой каталог данных. API-ключ хранится отдельно в Windows Credential Manager.

Диалог, включённая память и результаты инструментов из контекста отправляются DeepSeek. Аудио обрабатывается локально; распознанный текст отправляется для ответа.

## Сборка и проверки

`scripts/build.bat release` — сборка Release и размещение Qt рядом с EXE.
Требуются MSVC, Qt 6.11.1, CMake, Ninja и Vulkan SDK; подробности в `docs/BUILD.md`.

Проверка 7 сентября 2026: Release собран; 13 страниц открыты и отрисованы без ошибок QML. Общий отобранный прогон: 26 из 27 наборов прошли, ошибка в `tst_audio`. После последних изменений повторно прошли пять наборов: DeepSeek, конфигурация, голосовой контроллер, голосовой агент и защита от внедрения инструкций. Реальный запрос DeepSeek не проверен: сохранённого ключа и ключа в окружении нет. Подробности подключения: `docs/DEEPSEEK.md`.

## Команды и память (обновление)

Можно попросить «Открой Telegram» или назвать другую программу, у которой есть ярлык в меню «Пуск». Каталог собирается при запуске, максимум 300 ярлыков; после установки программы перезапустите Jarvis. Выбор программы по естественной фразе выполняет DeepSeek. Перед запуском действуют обычные разрешения инструмента. Это не выполнение произвольного кода или любой команды Windows.

«Запомни, меня зовут …» включает постоянную память и сохраняет факт. «Что ты помнишь?» показывает сохранённые факты. «Очисти память» удаляет их. Эти команды обрабатываются локально, до запроса к модели, и также работают для распознанной речи. Пароли, ключи и системные инструкции по-прежнему отклоняются фильтром памяти. Отдельные факты можно удалить на странице «Память».

## Голосовая активация и поиск

Включите голос на странице «Голос». Скажите «Жарвис», дождитесь «Слушаю, сэр» и произнесите одну команду в течение 15 секунд. Можно сразу сказать «Жарвис, открой калькулятор». Следующая команда снова требует обращения. Во время озвучивания нужно дождаться конца реплики; это предотвращает захват собственного ответа динамиками.

Активация использует локальное распознавание Whisper: микрофон и распознавание работают в режиме ожидания, но фразы без обращения не передаются агенту или DeepSeek. Это не отдельный маломощный детектор ключевого слова; задержка зависит от модели распознавания.

Примеры:
- «Жарвис, хочу на ютубе посмотреть обзор на новый айфон» — откроет результаты поиска YouTube в браузере по умолчанию.
- «Жарвис, информация про новый айфон» — откроет поиск Google.
- «Жарвис, приложение Telegram» — запросит запуск установленной программы по её ярлыку.

Открытие поиска и обычных приложений теперь относится к безопасным действиям без подтверждения. Общий выключатель инструментов и разрешение безопасных действий продолжают действовать. Закрытие программ остаётся с подтверждением из-за возможной потери несохранённой работы. Ярлыки удаления/установки/сброса исключены из обычного каталога запуска.

Поиск открывает готовый URL с запросом: Jarvis не выбирает ролик автоматически и не утверждает, что прочитал результаты. Голосовые ответы сокращаются примерно до 350 символов, полный текст остаётся в чате.

## CMD и PowerShell

Добавлены команды CMD/PowerShell с точным предварительным подтверждением, выводом результата, остановкой и лимитом 120 секунд. Готовые проверки сети, процессов, дисков и версии Windows работают без подтверждения. Примеры и ограничения: [docs/SHELL.md](docs/SHELL.md).
