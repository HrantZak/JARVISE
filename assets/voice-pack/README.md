# Архив пользовательских записей

Источник: предоставленный пользователем архив jarvis-voice-pack_da4b843fa7_VSTHEMES-ORG.rar. Исходные записи сохранены, но приложение больше не использует их для озвучки или клонирования.

Ответы, приветствие и короткие подтверждения теперь произносятся локальным нейросетевым голосом Piper: «Дмитрий» для русского, Ryan для английского. Системный Pavel не используется. Подача немного спокойнее: длительность фонем увеличена на 4%, пауза между предложениями — 0,22 секунды. Мягкое усиление низких частот добавляет теплоты тембру; высота голоса не сдвигается, эхо и модуляция не используются. Удаляется постоянное смещение сигнала, пики ограничиваются общим снижением громкости без обрезания формы волны. Это стилизация, а не копия голоса Жарвиса; правильное ударение в каждом слове не гарантируется.

Перед озвучкой удаляется оформление Markdown и применяется словарь чтения распространённых названий и сокращений: DeepSeek, YouTube, PowerShell, API и других. Это касается только звука: исходный ответ, команды и файлы не меняются. Числа, даты и неизвестные термины передаются движку без изменения значений.

Лёгкая выразительность применяется к коротким репликам: приветствия и подтверждения звучат немного бодрее, вопросы сохраняют вопросительный знак и получают чуть более длинную паузу, сообщения об ошибках читаются спокойнее. Темп меняется в пределах нескольких процентов; высота голоса не модулируется. Длинные технические ответы остаются ровными. Это настройка подачи по формулировке, а не модель актёрских эмоций. Отображаемый текст не изменяется.

Piper и голосовые модели уже установлены в `%USERPROFILE%/.helolo/voice`. Скрипт `install-windows-voice.ps1` оставлен для отдельно используемых системных голосов и не нужен текущей озвучке JARVIS.

Python и Chatterbox не нужны. Озвучка выполняется Piper на процессоре. Старые загруженные файлы в `build/voice-clone` не используются приложением.
